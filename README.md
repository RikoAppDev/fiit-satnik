# Šatník FIIT STU

Fakultný merch, ktorý nikdy nevznikol. Nuda o štvrtej ráno a tokeny, ktoré nebolo na čo páliť.

## Ako to rozbehať

Online: <https://rikoappdev.github.io/fiit-satnik/>

Lokálne:

1. Naklonuj repozitár.

   ```
   git clone https://github.com/RikoAppDev/fiit-satnik.git
   ```

2. Otvor `index.html` v prehliadači.

Nič sa neinštaluje ani nebuilduje. Ak chceš radšej lokálny server:

```
cd fiit-satnik
python3 -m http.server 8000
```

Potom otvor <http://localhost:8000>.
